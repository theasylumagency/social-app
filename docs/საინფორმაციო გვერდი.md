# Total Charm Dent

## ციფრული განვითარების სტრატეგიისთვის საჭირო ინფორმაცია

### გვერდის მიზანი

ეს გვერდი არის დროებითი სამუშაო ინსტრუმენტი, რომლის საშუალებითაც კლინიკისგან ვაგროვებთ მხოლოდ იმ ინფორმაციას, რომელიც საჭიროა ციფრული განვითარების სტრატეგიის მოსამზადებლად.

გვერდი არ არის საჯარო კონტენტი და არ უნდა ინდექსირდებოდეს საძიებო სისტემებში.

# 0. Intro Screen

### სათაური

**ციფრული განვითარების სტრატეგიისთვის საჭირო ინფორმაცია**

### ტექსტი

Total Charm Dent-ის ციფრული განვითარების სტრატეგიის მოსამზადებლად გვჭირდება რამდენიმე დამატებითი ინფორმაცია კლინიკის საქმიანობის, პაციენტების, მომსახურებებისა და არსებული მარკეტინგული პროცესების შესახებ.

ყველა კითხვაზე ზუსტი სტატისტიკური პასუხი აუცილებელი არ არის. თუ რომელიმე მონაცემი არ აღირიცხება, შეგიძლიათ მიუთითოთ მიახლოებითი შეფასება ან მონიშნოთ:

**„არ გვაქვს ინფორმაცია“**

შევსებული ინფორმაცია გამოყენებული იქნება მხოლოდ სტრატეგიის მოსამზადებლად.

### UI

* ღილაკი: **დაწყება**
* ტექსტი: „შევსებას დაახლოებით 10–15 წუთი დასჭირდება.“
* პროგრესი ჯერ არ ჩანს.

# UX პრინციპები

* ერთი ეკრანი = ერთი თემატური ბლოკი.
* მაქსიმალურად ნაკლები თავისუფალი ტექსტური ველი.
* „არ გვაქვს ინფორმაცია“ უნდა იყოს ჩვეულებრივი და სრულფასოვანი პასუხი.
* Progress bar: დაახლოებით **1/10, 2/10...**
* Back ღილაკი ყოველთვის ხელმისაწვდომია.
* პასუხები ავტომატურად ინახება თითოეული ნაბიჯის შემდეგ.
* Refresh-ის ან გვერდის დახურვის შემთხვევაში ინფორმაცია არ იკარგება.
* საჭიროების შემთხვევაში შესაძლებელი უნდა იყოს მოგვიანებით გაგრძელება.
* გაგრძელება შესაძლებელი უნდა იყოს სხვა მოწყობილობიდანაც.
* მხოლოდ შესაბამისი conditional კითხვები უნდა გამოჩნდეს.
* მობილურზე შევსება სრულად კომფორტული უნდა იყოს.

# ტექნიკური მოთხოვნები

* `noindex, nofollow`
* sitemap-ში არ შედის

* წვდომა მხოლოდ სპეციალური URL/token-ით

* გვერდი და შესაბამისი endpoint დასრულების შემდეგ მარტივად უნდა იშლებოდეს
